## 限制

尚无本项目独立模型 Key，真实模型工具验证和完整真实任务未运行。用户需按运行手册交互配置并显式执行验证命令。模型可用状态不等于任务成功率保证。

仍为 SSH 本人验证部署；没有公网 HTTPS、公开注册、邀请配额、正式备份恢复演练或硬 token 预算。会话历史有显式长度上限，接待失败后显式新一轮，不承诺中途透明恢复。看板在内存合并用户任务后分页，适用于当前低数据量，不是大规模查询方案。
